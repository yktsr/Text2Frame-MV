# Text2Frame Language Support

RPG ツクール MV/MZ 用プラグイン **Text2Frame** のスクリプトを、VS Code で快適に編集するための拡張機能です。シンタックスハイライト・入力補完に加え、編集中のテキストをそのままゲームデータへ反映する **Watch & Deploy** を備えています。

---

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 🎨 シンタックスハイライト | タグ（`<Face: >` など）・コメント（`%`, `<comment>…</comment>`）・`<script>` 内の JS・メッセージ本文を色分け |
| ✨ 入力補完 | `<` を入力すると 200 以上のタグ候補を表示（説明・スニペット付き） |
| 📖 ホバー説明 | タグにカーソルを合わせると使用例と説明を表示 |
| 🔍 診断 | 閉じ忘れの `<` `>`、空タグをリアルタイムに検出 |
| 🚀 Watch & Deploy | 編集中のテキストをゲームデータ JSON へ即反映（下記参照） |
| 📤 書き出し / 一括 | データ→テキストの書き出し、`text/` 一括デプロイ・一括書き出し |
| 🌐 英語化フロー | 言語を追加→編集→ゲームに反映を VS Code だけで完結（下記参照） |

---

## 🚀 Watch & Deploy — テキスト→データ即反映

編集中のテキストファイルを、ターミナルを使わずに RPG ツクールのデータ JSON
（`data/Map###.json` / `data/CommonEvents.json`）へコンパイルして書き戻します。

### 使い方

1. デプロイ先を示す **フロントマター** を持つテキストファイルを開く（下記参照）。
2. 操作する。入口は3つ:
   - **アクティビティバーの Text2Frame アイコン → 「操作 / Commands」パネル**（すべての操作をグループ別にクリック実行。下表の全コマンドがここに並びます）
   - コマンドパレット（`Text2Frame:` で検索）
   - エディタ右上のボタン（今のファイルを「ゲームに反映」/「ゲームから書き出し」）

覚えることは3つだけです ——「**言語を1つ選ぶ → ゲームに反映 / ゲームから書き出し → たまに競合をどちらか選ぶ**」。

| グループ | コマンド | 動作 |
| --- | --- | --- |
| ゲームに反映 | `ゲームに反映(このファイル)` | 今開いているテキストをゲームに反映 |
| ゲームに反映 | `ゲームに反映(すべて)` | 今の言語フォルダ `text/<言語>/` のテキストをすべて反映 |
| ゲームから書き出し | `ゲームから書き出し(このファイル)` | 今のファイルをゲームの内容で書き出し（テキストは上書き） |
| ゲームから書き出し | `ゲームから書き出し(すべて)` | ゲームの全イベントを `text/<言語>/` へ書き出し |
| 言語 | `言語を追加` | ゲームの内容を今の言語フォルダに複製して着手（既存ファイルは残す） |
| 上級 | `コンパイル結果を表示` / `保存時に自動反映 切替` / `会話のみ書き出し` | 補助操作 |

ステータスバーに現在の状態と直近の結果が表示されます。

| 表示 | 意味 |
| --- | --- |
| `$(eye) T2F: watching` | 自動デプロイ ON |
| `$(circle-outline) T2F: off` | 自動デプロイ OFF |
| `$(check) T2F ok` | 直近のデプロイ成功（警告数も表示） |
| `$(error) T2F fail` | 直近のデプロイ失敗（詳細はツールチップ／通知） |

### デプロイ先はフロントマターで決まる

ファイル先頭の YAML フロントマター（`kind` / `mapId` / `eventId` / `pageId` /
`commonEventId`）から書き戻し先を判定します。ファイル単体で宛先が決まります。

```text2frame
---
kind: event
mapId: 1
eventId: 1
pageId: 1
---

<Face: Actor1(0)>
こんにちは
```

コモンイベントの場合：

```text2frame
---
kind: common
commonEventId: 3
---

セリフ…
```

### ゲームに反映するときの動き（既定は「安全に反映」）

「ゲームに反映」は既定で**安全**です（設定 `text2frame.strategy` の既定＝安全に反映）。
**テキストの編集**と、**ツクールのエディタで加えた編集**の両方をできるだけ両立させ、勝手に消しません。

- 同じ場所を**両方で別々に**変更していたときだけ、**両方を残して**あなたに選んでもらいます（下記の競合表示）。
- テキストにしか無い会話は反映し、ゲーム側にしか無い構造（移動・分岐・スイッチ等）は保持します。
- 「全部テキストで上書きしたい」ときだけ、設定を **全部上書き** にしてください（ゲーム側の編集は消えます）。

#### 競合したときの表示と解決
同じ場所を両方で変更していると、その部分は**両方残り**、目印コメントで囲まれます（タグ記号 `< >` を使わないので文法警告は出ません）:

```
=== テキストの変更 / from text ===
（テキスト側の内容）
=== ゲームの変更 / from game ===
（ゲーム側の内容）
=== どちらかを残し、この目印3行を消す / keep one, delete these 3 marker lines ===
```

どちらか＋目印3行を消せば解決です。この書き戻しは設定 `text2frame.writeBackAfterMerge` で調整できます（既定＝競合したときだけ書き戻す / 反映のたび / しない）。

### 安全のしくみ

- **データ変更ガード**: デプロイ先 JSON が、拡張が最後に書き込んで以降に**外部で更新**(RPG ツクール等)されていて、かつ設定が **全部上書き** のときだけ、上書き前に確認ダイアログを表示します（既定の「安全に反映」はゲーム側の編集を保持するため確認は出ません）。
  - **[安全に反映する(おすすめ)]** … その回だけ安全に反映し、ゲーム側の編集を保持
  - **[全部上書きする]** … テキストで上書き(直前の JSON を `*.json.conflict.bak` に退避)
  - **[ゲームの内容を取り込む]** … 反映せず、最新データをテキストへ書き出して取り込む
  - **[キャンセル]** … 何もしない
- 最初の書き込み前に、対象 JSON のオリジナルを `*.bak` として 1 度だけ退避します。
- 文法エラー時は書き込まずに中断し、エラーを通知します。
- 差分の警告・エラーは通知と **Text2Frame Deploy** 出力チャンネルに表示されます。
  - ブロックの**内容変更**は「`Block changed / ブロックが変更されます`」、
    テキストから消えて**削除されるブロックのみ**「`Block removed / ブロックが削除されます`」と報告されます。

> ⚠️ デプロイは稼働中の `data/` JSON を直接書き換えます。反映を確認するときは
> RPG ツクールのエディタを **保存せずに** 開き直してください。

### 設定

| 設定キー | 既定値 | 説明 |
| --- | --- | --- |
| `text2frame.locale` | `ja` | **作業する言語**（`text/<言語>/` フォルダ）。例 `ja` / `en`。反映・書き出し・言語追加はこの言語フォルダを対象にします |
| `text2frame.strategy` | 安全に反映 | ゲームへの反映のしかた。**安全に反映**（ゲーム側の編集を消さない・既定）/ **全部上書き**。通常は既定のままで大丈夫です |
| `text2frame.writeBackAfterMerge` | 競合したときだけ | 競合したとき、結果をテキストに書き戻して確認・解決できるようにするか。しない / 競合時だけ(既定) / 反映のたび |
| `text2frame.modulePath` | （空） | `Text2Frame.js` のパスを明示指定（空なら自動解決） |
| `text2frame.dataDir` | `data` | データフォルダ(ワークスペース相対) |
| `text2frame.textBaseDir` | `text` | テキストの基準フォルダ(ワークスペース相対) |

### 動作要件

本拡張は **VS Code に内蔵された Node ランタイム（拡張ホスト）** 上でコンパイラ
（`Text2Frame.js`）を読み込みます。そのため **Windows ネイティブの VS Code で
そのまま動作し**、Node.js を別途インストールする必要はありません。

コンパイラの解決順は次のとおりです。

1. 設定 `text2frame.modulePath`（明示指定がある場合）
2. 拡張に同梱した `lib\Text2Frame.js`（パッケージ版）
3. モノレポ兄弟 `..\Text2Frame.js`（開発時）
4. 開いているワークスペース内の `Text2Frame.js`（`js\plugins\Text2Frame.js` も探索）

## 🌐 英語化フロー（VS Code だけで完結）

このツールに「翻訳」という独立した機構はありません。あるのは **言語ごとの
`text/<言語>/` フォルダを、ゲームと行き来させること**だけです。設定「言語」を
`en` にして、次の3ステップで英語版を作れます。

1. **言語を追加** — 「操作」パネル →「言語を追加」。
   - ゲームの内容を `text/en/` に複製し、翻訳の着手点を作ります（本文はまず原文と同じ）。
   - **既存ファイルは上書きしません**（作業途中で再実行しても安全）。
2. **編集する** — `text/en/` の本文・選択肢を翻訳します。
   - front matter とタグ（`<Face..>` 等）、空行マーカー `<br>` は触らないでください。
3. **ゲームに反映** — 「ゲームに反映(すべて)」を実行。
   - 既定は**安全に反映**：ツクール側で加えた編集（移動・分岐・スイッチ等）を保ちつつ、翻訳を反映します。
   - 同じ場所を両方で変更していたら、その部分だけ**両方残して**あなたに選んでもらいます（前述の競合表示）。
   - 全部テキストで上書きしたいときだけ、設定「反映のしかた」を**全部上書き**にします。

> **「ゲームから書き出し」との違い**: 「ゲームから書き出し」はゲームの内容で**テキストを上書き**します（テキスト側の編集は失われます）。編集を保ちたいときは「書き出し」ではなく「**ゲームに反映**」を使ってください。

> 個別ファイルを編集中に保存→即反映したい場合は、「保存時に自動反映」を ON にすると、front matter の宛先へ自動で反映されます（既定は安全に反映）。

## 編集例

`.t2f` または `.text2frame` 拡張子のファイルを作成して編集します。

```text2frame
<comment>
* オープニングシーン
</comment>

今日も一日がんばるぞい！

<Face: Actor1(0)>
今日も一日がんばるぞい！（顔付き）

<WindowPosition: Bottom>
<Background: Dim>
<Name: 涼風青葉>
今日も一日がんばるぞい！

% コメント行
<PlayBGM: Theme1>

<ShowChoices: Window, Right, 1, 2>
<When: はい>
そうですか！
<When: いいえ>
残念です。
<End>

<wait: 60>
```

## 対応タグ（抜粋）

**表示設定**

| タグ | 説明 |
| --- | --- |
| `<Face: >` | 顔グラフィック |
| `<WindowPosition: >` | ウィンドウ位置（Top / Middle / Bottom） |
| `<Background: >` | 背景（Window / Dim / Transparent） |
| `<Name: >` | 名前（MZ） |

**イベントコマンド**

| タグ | 説明 |
| --- | --- |
| `<ShowChoices: >` / `<When: >` / `<End>` | 選択肢と分岐 |
| `<Switch: >` / `<Set: >` / `<If: >` | スイッチ・変数・条件分岐 |
| `<PlayBGM: >` / `<PlaySE: >` | オーディオ |
| `<wait: >` | ウェイト |
| `<script>…</script>` | JavaScript の実行 |

…ほか 100 以上の RPG ツクールイベントコマンドに対応しています。

## 開発

```bash
npm install        # 依存をインストール
npm run compile    # TypeScript をビルド（out/）
npm run watch      # 変更を監視してビルド
npm run lint       # ESLint
```

`F5` で Extension Development Host を起動するとデバッグできます。

パッケージ（`.vsix`）化の前に、同梱コンパイラを生成します（`vscode:prepublish` で自動実行）。

```bash
npm run bundle-compiler   # 親リポジトリの Text2Frame.js を lib/ にコピー
```

## 情報

- **対象拡張子**: `.t2f`, `.text2frame`
- **`.txt` の自動認識**: Text2Frame のフロントマター(`---\nkind: ...`)を持つ `.txt` を開くと、自動的に text2frame 言語として扱い、ハイライト・補完・ホバー・診断が有効になります(リネーム不要)。フロントマターの無い通常の `.txt` は対象外です。
- **必要環境**: VS Code 1.85.0 以上
- **ライセンス**: MIT
