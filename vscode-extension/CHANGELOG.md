# Change Log

Text2Frame Language Support の変更履歴です。
版の番号は、マイナー版が奇数（`0.1.x`）なら pre-release、偶数（`0.2.x`）なら安定版です。

## [0.1.3] - 2026-09-21 (pre-release)

最初の公開版です。RPG ツクール MV / MZ のイベントを、VS Code でテキストとして書き、ツクールと同じ形で確かめ、ゲームに反映してテストプレイできます。

### テキストを書く

- タグの色分け、`<` で出るタグの候補、タグにマウスを合わせると出る説明。
- 書き間違いの指摘: `< >` の閉じ忘れ、空のタグ、タグとして読まれずにゲームにそのまま文字で出る行、ウィンドウの幅からはみ出すメッセージ。
- スイッチ・変数・アイテムなどの番号の横に、データベースの名前を薄く表示。名前から番号を探して入れる候補も出ます。
- 顔画像・キャラ画像・ピクチャ・BGM・BGS・ME・SE を一覧で見て（音は試し聞きして）選び、カーソルの行に入れる「素材を選ぶ」。
- 電球からの直し方: 近いタグの名前に直す、閉じ忘れを足す、空のタグを消す、番号を選び直す、はみ出した行を改行する、衝突の目印のどちらを残すか選ぶ。
- 行の頭で `/` を打つと出るスニペット。選んだ部分から自分のスニペットも作れます。
- 定義へ移動・参照の一覧・名前で開く・アウトライン・折りたたみ。

### プレビュー

- 書いたテキストを、ツクールのイベント編集画面と同じ形で横に表示。顔画像も出て、BGM・効果音はその場で鳴らせます。
- エディタのカーソルの行と連動し、プレビューの行を押すとテキストのその行へ飛びます。

### ゲームとやりとりする

- 「ゲームから取り出す」「ゲームに反映」を、開いているテキスト・テキストのフォルダ全部・一覧の1ページの単位で。
- テキストとツクールの両方の編集を残して合わせる統合（3-way マージ）。同じ所を両方で変えていたときは、操作を始めた側に両方の版と衝突の目印を入れます。
- 書き込む前に、変わる所を差分の画面で確かめる。
- 保存するたびにゲームへ反映する「保存時に自動反映」。
- 反映・取り出しの前の中身を自動で控え、あとから操作の前に戻せる「履歴」。

### プロジェクトを調べる

- マップ → イベント → ページの一覧（出現条件とトリガー、未反映の印つき）と、データベースの一覧。
- スイッチ・変数を使っている所の一覧。そのスイッチや変数が出現条件になっているページも出ます（テキストの無いページには印）。
- イベントのつながり（呼ぶコモンイベント・移動先・変えるスイッチと、それで出てくるページ）を呼び出し階層でたどる。
- 場所移動でつながるマップの一覧と図。
- 全部のテキストを調べて「問題」パネルに出す「プロジェクト全体を検査」。

### テストプレイとデバッグ

- VS Code の中でテストプレイ（テストモード）。
- テストプレイ中のスイッチ・変数・セルフスイッチ・アイテム・所持金を見て書き換える「デバッグメニュー」。イベントごとに今出ているページ（`P1/2`）と、ページの出現条件を満たしているかが分かります。
- テキストから「▶ イベントの前に立つ」「▶ このページをすぐ実行」で、そのイベントをすぐ試せます。
- 今動いているイベントの行に色を付けて表示。
- 印をつけた行でゲームを一時停止し、値を見たり1行ずつ進めたりできます（「操作」→「上級」でオンにしたときだけ）。

### 表示の言語

- 画面の言葉は、VS Code の表示言語に合わせて日本語か英語で出ます。

### 動かすのに必要なもの

- VS Code 1.85.0 以上。テキストとゲームのデータの変換には、同梱の Text2Frame を使います（Node.js などを別に入れる必要はありません）。
